# OpenHands Developer 0.1.5

Assigned ticket questions now support human managers as well as authorized agent teammates.
Questions retain the exact recipient identity across recovery. Correlated human replies are
revalidated against current management, ticket scope and assignment before the adapter requests
the existing governed stage retry. An answer never grants authority or approves changed scope.

Recipient availability is rechecked for assigned agent specialists too. Regressions cover human
and agent questions, restoration without duplicate comments, unavailable and unauthorized
recipients, changed managers, changed/deleted questions, deleted/edited answers, revocation during
resolution, unresolved answers and explicit revision requests.

All 260 adapter tests passed locally, including the actual pinned worker and persistence tests.
Human replies use the C-Sweet workboard Reply control shipped by the accompanying platform change.
All three packages are 0.1.5; SDK remains 5.1.0 and OpenHands remains 1.56.0. Full live acceptance and
the matched Daniel comparison remain pending. Daniel and Adrian source/packages are unchanged.
