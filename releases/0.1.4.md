# OpenHands Developer 0.1.4

Fixes a live pilot failure where OpenHands supplied a default `high` reasoning effort that the
selected Qwen provider rejected. Worker model calls now retain C-Sweet provider/model defaults;
the full configured context window and output budget are preserved.

Personal-plan worker/provider failures now remain operational blockers without consuming the code
repair budget. Known worker failure categories and phases provide sanitized diagnostics without
copying exception messages, credentials or model/tool payloads into activity.

Regression coverage includes the actual pinned worker with default and live token budgets,
provider-default reasoning, reported worker failure, diagnostic sanitization and personal-plan
operational recovery. Genuine invalid-outcome and failed-validation repairs remain bounded.

All three packages are versioned 0.1.4; SDK remains 5.1.0 and OpenHands remains 1.56.0.
Full live acceptance and the Daniel comparison remain pending. Daniel and Adrian source and
installed packages are unchanged.
