# OpenHands Developer 0.1.3

Carry the published developer 2.1.2 shell-policy recovery behavior into the shared development adapter,
without modifying Daniel or Adrian. Policy denials now reach OpenHands as actionable tool results;
denied commands never start a process, prepare resources, or receive exit-code/validation receipts.
Permitted work resets the denial count. Three consecutive denials stop implementation, retain authored
source and report an operational blocker. Restrictions and grants remain unchanged.

Verified with policy/preparation/progress tests and actual pinned OpenHands worker scenarios for both
permitted continuation and bounded repeated-denial recovery. The full agent suite contains 238 tests.
All three packages are versioned 0.1.3; SDK remains 5.1.0 and OpenHands remains 1.56.0.
