# OpenHands Developer 0.1.7

Personal-plan execution can read current board tickets, read their comments and post factual progress through typed C-Sweet operations. Ticket IDs are checked against the current authorized board before each operation, and repeated comments use stable workspace/content idempotency keys.

Comments cannot change assignments, requirements, approvals or execution status. Source-only notes are no longer presented as a substitute for an explicitly requested workboard update.
