# OpenHands Developer 0.1.0

Initial isolated OpenHands developer pilot for C-Sweet.

- Adds the reusable `CSweet.Agent.Development` workflow adapter and `CSweet.Agent.OpenHands` execution engine, both version 0.1.0.
- Uses pinned OpenHands SDK/tools 1.56.0 with hash-locked automatic runtime setup in the certified Linux guest.
- Integrates ticket execution, discussion, progress, manager escalation and governed resume, planning, review/rework, source validation and delivery workflows through SDK 5.1.0.
- Routes model access through C-Sweet, retains private source/engine checkpoints, and supplies brokered SearXNG research and bounded public page reading.
- Keeps Daniel and Adrian unchanged. Adoption remains opt-in; live comparison results are recorded separately from automated verification.

Requires the C-Sweet platform's SDK 5.1.0 research/checkpoint handlers and reviewed grants.
