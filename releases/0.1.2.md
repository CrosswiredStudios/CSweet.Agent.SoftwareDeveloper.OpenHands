# OpenHands Developer 0.1.2

Runtime setup, missing Python executables, early worker exits and finalization failures now retain
their operational failure category. These failures cannot be mistaken for completed development or
sent to technical leadership as architecture questions. Existing source and conversation checkpoints
remain available for governed recovery.

The independent package consumer now uses an explicit NuGet configuration so multiple feed URLs
restore consistently on Windows and Linux.

Verified with missing-executable and premature-exit regression tests plus the pinned OpenHands worker
execution/restoration suite. OpenHands SDK and tools remain pinned to 1.56.0; SDK dependency remains 5.1.0.
